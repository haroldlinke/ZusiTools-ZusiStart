Bremse lösen:

Drücken Sie die Minus-Taste (Zehnerblock) so oft, bis das Führerbremsventil in der vorderen Stufe (Fahrt) liegt. Der Druck in der Hauptluftleitung muß auf 5 bar steigen und der Bremszylinderdruck auf 0 bar sinken.

Bleibt noch Druck im Bremszylinder, so ist evtl. die Zusatzbremse noch angelegt. Zum Lösen 2x die Plus-Taste (im deutschen Layout über der #-Taste) drücken.

Bremskraft verringern: Soll die Bremskraft lediglich verringert werden, so drücken Sie die Minus-Taste (Zehnerblock) entsprechend oft. Mit jedem Druck wird der Druck in der Hauptluftleitung um eine Stufe angehoben und die Bremsung entsprechend geringer.
